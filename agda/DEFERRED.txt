# DEFERRED.txt — passed-only lemma ledger.  EMPTY, AND THAT IS THE POINT.
# Maintained by the ratchet in `make wiring-gate` (see scripts/check-wiring.py).
#
# WHAT THIS FILE IS — A FROZEN GRANDFATHER LIST THAT MAY ONLY SHRINK.
# The wiring law tracks NAMES, not OBLIGATIONS INSIDE TYPES.  A proven lemma
# whose only consumers are assembly argument positions (i.e. it is PASSED into
# a postulate but never APPLIED) reads as fully wired — no orphan, no gate
# failure — while its own premises sit permanently unpaid as long as the
# parent postulate stands.
#
# THE LEAF-ONLY RULE (Anthony, 2026-08-15) — WHY THE LIST WAS FROZEN.
# Passed-only is NOT "normal while the parent is a postulate".  It is the
# state the rule exists to prevent, because such a lemma has never had its
# FIT tested: nothing reduces it, so nothing checks that its type is the one
# the parent actually needs.  A postulate must be a LEAF — write an assembly
# as a REAL BODY over POSTULATED LEAVES, never as a postulate over proven
# pieces, where the composition is asserted and checked by nobody.
#
# THE MIGRATION IS COMPLETE (2026-08-18).  Four parents landed, and every one
# of them found something its route list had hidden:
#   · subscribeE-input-wf-core  — exposed the missing `ltok`, now the
#     `hot-live` field on Inv/BurstInv; and its cold/no-async arm turned out
#     to be `oneShotBurst` verbatim, closed outright.
#   · innerReact-nodry-core / thruOuter-nodry-core — two cores became bodies
#     dispatching over the evaluator's own arms; the fit test billed the two
#     -slFc leaves their depth premises.
#   · subscribeE-takeᵉ-wf-core — STOPPED on a premise (`dyF`) that is FALSE at
#     its only call site, then RESUMED by a ruling rather than a proof: keying
#     `BurstInv.live-matches` off `EvalSt.dying st` removed the premise instead
#     of repairing it.  Its zero arm was free.
#   · dry-tick-core — NINE lemmas, EIGHT of which were never ingredients.  The
#     conclusion is `cascadeGo`'s stream verbatim (cascadeFinish emits
#     nothing), so no bound and no ledger fact could enter it, and the ninth
#     could not be applied until the statement gained the `capsOK?` its own
#     INV? provably cannot supply.
#
# THE LESSON THE LAST ONE TAUGHT, worth more than the count: an argument list
# is a HYPOTHESIS ABOUT A ROUTE, not a specification.  Eight proven lemmas had
# been PARKED in one, which read as fully wired for months.  Applying the
# ninth is what proved the other eight were never ingredients — and under this
# rule a proven lemma has no legal home but a real consumer, so they and three
# modules that nothing else reached were deleted.  A RECOVERY pointer sits on
# `hop-edge`'s header (.Wet/Part6), where the walk grind will want them back.
#
# HOW THE RATCHET WORKS, and why the file stays.
# `make wiring-gate` compares the measured passed-only set against this file:
#   - a lemma measured but NOT listed here = LEAF-ONLY VIOLATION — fails the
#     gate.  The remedy is to write the parent's body, NOT to add a line here.
#     Adding a line increases tracked debt and needs an explicit ruling from
#     Anthony.  With the list empty, ANY new passed-only lemma fails;
#   - a lemma listed but NOT measured = its premises are now discharged (or the
#     lemma was deleted) — the ledger line must go.  That is how this file got
#     to zero, and there is nothing left to remove.
#
